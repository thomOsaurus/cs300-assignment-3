# CS300 Assignment 3: JavaScript Data Toolkit

**Student:** Thomas Olivares

**Scenario:** Book Collection

**Route:** Console (Node.js)

## Project Description
This project helps Mina organize and explore a collection of eight fictional books, The JavaScript toolkit will validate, normalize, filter, search, sort, and summarize the collection.

## How to Run
1. Open the repository in VS Code
2. Open a terminal
3. Run 'node harness.js'
4. Review the PASS/FAIL verification results

## Files
- 'toolkit.js' - Seven JavaScript functions
- 'harness.js' - Verification results
- 'data/books.json' - Book collection dataset
